# 1.17.40-dev8

## 主要更新

- 使用 Kotlin 重写启动器界面、设置、更新、资源提取和主题逻辑。
- 构建系统迁移到 Gradle Wrapper、Android Gradle Plugin 和 Kotlin DSL。
- 接入官方 Material 3 DayNight 主题与 Material Components 控件。
- 保留自定义主题色、深色模式、动态壁纸取色和实时预览。
- 在“关于”页面新增现代化重写说明，并补齐多语言翻译。
- 启动按钮改为更明显的胶囊圆角样式。
- 最低系统版本调整为 Android 7.0（API 24）。
- SDL、音频、控制器和原生兼容层继续保留 Java 实现，避免影响引擎行为。

## 构建信息

- `minSdk`: 24
- `targetSdk`: 29
- `compileSdk`: 34
- Material Components: 1.12.0
